# 06: 块布局状态迁入块清单，跨设备生效

**What to build:**
块的高度和折叠状态跟着页面走，不跟着设备走。在电脑上调好的布局，用手机打开同一个页面就是同样的布局。现有设备上已经调好的布局一次性迁移过去，不丢。页面刚打开、还没连上服务器时先按上次的布局渲染，不会先以默认高度出现再跳一下。完整背景见同目录
`spec.md`。

因为落点是协同文档，布局状态**对该页面的所有查看者共享**。这是有意为之的取舍（无账号系统，跨设备同步与个人视图隔离只能二选一），已由票 01 的 ADR 记录。

块条目的目标形状（由原型确定，`folds` 字段留给票 07）：

```ts
type BlockInfo = {
  id: string;
  title: string;
  language: string;
  height?: number; // 未设置时按默认值渲染
  collapsed?: boolean; // 未设置时按展开渲染
};
```

**Blocked by:** 02, 03, 05

**Status:** ready-for-agent
