# 07: markdown 标题折叠状态记忆

**What to build:**
markdown 块里折叠起来的标题段落，刷新页面后仍然折叠，换一台设备打开也一致。别人改动了块内容、行号漂移之后，对不上的折叠记录自动放弃，不会把错误的行藏起来。完整背景见同目录
`spec.md`。

折叠记录**原样存放 Monaco 的折叠 memento**，不做压缩或转格式：Monaco 自己校验它（非数组直接忽略，每个折叠区带内容校验和，对不上就跳过该区），这正是内容变动后自愈的机制，换成自定义格式会丢掉它。

两个已核实的约束：整体编辑器视图状态的恢复接口要求光标状态与视口状态同时存在，只传折叠部分会被完整忽略，因此必须走折叠贡献而不是整体视图状态；折叠范围是异步去抖计算的，内容同步完成后立刻恢复会因为折叠区尚未算出而静默无效。
