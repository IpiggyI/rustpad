# 05: 块快照存储加固：可注入存储、配额淘汰与降级

**What to build:**
本地缓存写满时应用继续正常工作，不再抛异常打断编辑。空间不够时优先淘汰其他页面的旧缓存，保住当前正在编辑的页面。仍然放不下时降级为只缓存块的元信息、放弃缓存正文。完整背景见同目录
`spec.md`。

降级顺序的依据：服务端有永久持久化，正文丢了还能从服务端取回；块元信息丢了才会找不到块。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 块快照模块的存储对象改为可注入，便于测试驱动异常路径
- [ ] 快照写入失败不向外抛异常
- [ ] 捕获到配额溢出时，按最后访问时间淘汰其他页面的快照并重试
- [ ] 重试仍失败时降级为只写块元信息、不写正文
- [ ] 读到损坏内容时返回「无快照」而不是抛异常
- [ ] 有测试：注入一个写入时抛配额异常的存储对象，分别断言不外抛、触发淘汰、重试、降级四条路径
- [ ] 有存取往返测试：写入后读出的结构一致
- [ ] 类型检查通过、测试通过
- [ ] 实机验证：把本地存储灌到接近上限后继续编辑，编辑过程不中断
