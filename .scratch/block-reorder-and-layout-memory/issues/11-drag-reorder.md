# 11: 拖拽排序

**What to build:**
按住块头部最左侧的拖拽手柄，把块直接拖到新位置，松手生效。拖拽过程中其他块实时让位，能预判落点。拖拽期间不产生任何网络写入，只在松手时提交一次；在你拖拽期间其他设备新增或删除的块不会被你的拖拽结果抹掉。完整背景见同目录
`spec.md`。

拖拽用项目已有的动画库（同时也是 UI 组件库的依赖），**不引入新依赖**。关闭组件自带的整项拖拽监听，改由专用手柄发起，避免整块可拖导致编辑器内选不中文字。布局动画限定为只动位置、不动尺寸 —— 尺寸动画会持续触发编辑器的自动布局重算，多个编辑器同屏时会卡顿。

不做拖到屏幕边缘时的自动滚动：动画库不提供该能力，长距离移动由票 10 的置顶置底覆盖。

**Blocked by:** 03, 10

**Status:** ready-for-agent

- [ ] 块头部最左侧有拖拽手柄，按住可以拖动整个块
- [ ] 只有手柄能发起拖拽；块头部其他区域与编辑器正文不能
- [ ] 编辑器正文里的文字选中与拖选不受影响
- [ ] 拖拽过程中其他块实时让位
- [ ] 拖拽期间不产生任何块清单写入；松手时提交一次
- [ ] 提交时按块 id 在当前清单里重新定位，而不是用本地数组整份覆盖
- [ ] 拖拽期间其他客户端新增或删除的块，在提交后仍然存在
- [ ] 布局动画只作用于位置、不作用于尺寸
- [ ] 不新增任何第三方依赖
- [ ] 触摸设备上手柄同样能发起拖拽
- [ ] 块清单操作模块新增按 id 重定位函数，测试覆盖含目标 id 或参照 id 已不存在的情况
- [ ] 类型检查通过、测试通过
- [ ] 实机验证：20 个块同屏时拖拽流畅，编辑器不闪烁、不卡顿
- [ ] 实机验证：手机上能用手柄重排
