# 03: 抽出块清单操作纯函数模块（纯搬移）

**What to build:**
块清单的增删改移从 React 钩子里搬进一个纯函数模块，用户可观察的行为完全不变，但从此可以脱离 React 单独测试。这是后续六张票的地基。完整背景见同目录
`spec.md`。

**本票只搬移当前已有的行为。**
置顶置底、按位置添加、更新布局、结构校验、遗留迁移等函数由各自的票在这个模块上生长，不在本票一次抽干净。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 存在一个不依赖 React 的纯函数模块，承载块清单的解析、序列化、添加、删除、上移、下移、更新块字段
- [ ] 本票不新增任何函数、不改变任何可观察行为
- [ ] 块清单 React 钩子只保留协同同步与状态管理，所有清单转换调用该模块
- [ ] 模块测试覆盖：上移、下移、添加、删除、更新块字段
- [ ] 边界用例均断言「无变化」：首位上移、末位下移、单块清单、空清单、目标 id 不存在
- [ ] 解析测试覆盖：正常清单、空文本、非法 JSON
- [ ] 若尚不存在，添加一个一条命令跑完所有测试文件的 npm 脚本
- [ ] 类型检查通过、测试通过
- [ ] 实机回归：添加块、删除块、上移、下移、改标题、改语言，行为与改动前一致
