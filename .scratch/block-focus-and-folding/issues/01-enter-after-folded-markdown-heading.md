# 01：在折叠 Markdown 标题后回车创建同级标题

**What to build:**
在单文档模式和分块工作区中，用户于已折叠 Markdown 标题末尾按普通回车，可在整个折叠区之后继续编写同级标题，原内容保持折叠。

**Blocked by:** 无，可立即开始。

**Status:** ready-for-agent

- [ ] 仅在 Markdown、单光标、无选区、光标位于已折叠标题行末且没有处于输入法组合期间时触发新行为。
- [ ] 在当前折叠区的全部内容之后插入同级标题，沿用原来的标题级别，不复制标题文字；新标题标记后保留一个空格，光标停在该空格之后。
- [ ] 原折叠内容保持隐藏，新标题可见；验证正文内容、实际隐藏范围与光标位置，不能只验证插入字符串。
- [ ] 折叠区包含子标题时，插在全部子标题内容之后；文末和已有后继同级或更高级标题两种情况均正确处理，不修改既有正文。
- [ ] 两种模式使用相同语义。其他语言、展开的标题、标题中间、多光标、选区、带其他修饰键的命令和输入法组合期间保持原有行为。
- [ ] 输入法候选确认用的回车不额外创建标题，组合结束后的正常回车仍可触发。
- [ ] 插入作为一次可撤销正文编辑，撤销与重做得到正确正文；另一客户端收到相同插入，现有协同机制继续工作。
- [ ] 用项目测试覆盖可独立验证的边界，并用真实编辑器执行两种模式的上述场景；检查能在插入位置、级别、折叠或光标行为错误时失败。
