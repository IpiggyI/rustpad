# 02：将堆叠展示的块正文高度统一调整为 200 像素

**What to build:**
堆叠展示使用更紧凑的块正文高度，同时完成已有页面的一次性高度调整，让用户看到更多块，并继续保留升级后的手动调整。

**Blocked by:** 无，可立即开始。

**Status:** ready-for-agent

- [ ] 新块默认正文高度为 200 像素，不含块头部，仍支持拖动调整高度。
- [ ] 已有页面首次完成升级调整时，所有已有块的正文高度统一为 200 像素，包括已保存的手动高度和当前整块折叠的块。
- [ ] 每个页面只调整一次。之后手动改变高度，刷新、关闭重开或另一设备打开页面都不得再次重置为 200 像素。
- [ ] 高度继续按页面共享；升级完成后，另一设备看到相同高度，不能依据自己的旧缓存再次执行迁移。
- [ ] 调整只改变块高度及必要的升级记录，不改变正文、标题、语言、顺序、整块折叠或块内折叠。
- [ ] 升级记录经过现有块清单读写和规范化后仍能保留；不得把首屏缓存或尚未就绪的清单误认为需要重新迁移的权威记录。
- [ ] 空页面也能完成升级处理；以后添加的块使用新默认值，不因升级而自动增加块。
- [ ] 测试覆盖有无旧高度、重复加载、旧缓存和第二设备打开；真实浏览器验证正文区域尺寸及升级后拖动再重开的高度保留。
