# 07：通过侧栏菜单和拖拽调整块顺序

**What to build:**
用户能在侧栏直接调整块顺序，使用菜单完成精确移动，使用鼠标或触摸手柄拖拽并在长列表边缘自动滚动。

**Blocked by:** 03：通过侧栏选择和定位当前块。

**Status:** ready-for-agent

- [ ] 每个侧栏项提供排序菜单，沿用上移、下移、置顶和置底语义；边界操作不改变顺序。
- [ ] 只有专用手柄启动拖拽，点击导航、命名、语言选择、菜单和正文选区操作不会误触发排序。
- [ ] 鼠标和触摸均能拖拽，界面明确显示预期落点；侧栏列表较长时，靠近上方或下方边缘会向对应方向自动滚动。
- [ ] 拖拽期间只在本机预览顺序，松手才提交排序；取消或中断拖拽不写入未完成的预览结果。
- [ ] 提交基于稳定块身份和最新清单定位，拖动期间远端新增或删除的块不被陈旧数组覆盖。
- [ ] 移动目标已经被远端删除时安全结束操作，不重新创建该块；本票不扩大现有同步层对人为并发结构修改的保证。
- [ ] 排序后仍选中同一块，正文、标题、语言、高度和折叠记录不变；其他设备收到块顺序变化，但不跳转当前块。
- [ ] 堆叠展示保留现有块头部排序入口，侧栏与块头部操作体现同一顺序。
- [ ] 测试覆盖移动边界、相对顺序及拖拽期间清单变化；真实浏览器验证鼠标、触摸、长列表自动滚动、取消和提交次数。
