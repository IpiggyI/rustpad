# 03：通过侧栏选择和定位当前块

**What to build:**
先在现有堆叠展示中打通侧栏导航：用户能选择块、定位到对应块，并由本机按页面记住当前块，为后续单块展示与侧栏管理提供完整的当前块行为。

**Blocked by:** 无，可立即开始。

**Status:** ready-for-agent

- [ ] 侧栏列出全部块并明确标识当前块，使用稳定的块身份，不依赖名称唯一性或数组位置。
- [ ] 点击侧栏项会选中该块并滚动到它；整块已经折叠时定位到块头部，不自动展开。
- [ ] 直接编辑另一个块时，该块成为当前块；普通滚动不持续改变当前块。
- [ ] 当前块按设备、按页面分别记住。刷新或关闭重开后恢复有效记录，没有有效记录时选第一个块，空页面没有当前块。
- [ ] 本机选择不写入共享块清单；另一设备查看同一页面时，不因本机切块而跳转。
- [ ] 排序后保持选中同一块。删除非当前块不改变选择；当前块被本机或远端删除时，优先选原顺序中的后一个，其次前一个。
- [ ] 无法从已有顺序确定相邻块时选择现有第一个块；清单为空时清除当前选择，不留下失效的块身份。
- [ ] 点击或编辑引起的当前块变化不会清空正文、重置已有折叠或丢弃正在同步的输入。
- [ ] 测试覆盖选择恢复、页面隔离、同名块、排序及删除回退；真实浏览器验证定位、折叠块跳转和两个客户端的选择独立性。
