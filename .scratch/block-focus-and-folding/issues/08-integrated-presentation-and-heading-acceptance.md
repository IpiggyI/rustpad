# 08：验收分块展示与 Markdown 回车的组合行为

**What to build:**
在各功能票已独立验证的基础上，验证新展示方式、侧栏管理和 Markdown 回车组合使用时的完整体验，记录自动化、双客户端和实机验证边界。

**Blocked by:**
01：在折叠 Markdown 标题后回车创建同级标题；02：将堆叠展示的块正文高度统一调整为 200 像素；04：默认使用单块展示并保留切块时的编辑状态；05：在侧栏新增、命名和选择块语言；06：确认删除块并保留零块页面；07：通过侧栏菜单和拖拽调整块顺序。

**Status:** ready-for-agent

- [ ] 确认前置票据各自的行为检查已经完成；本票补充跨功能场景，不替代前置票据验证。
- [ ] 从已有页面升级到紧凑高度，切换两种展示，手动调整高度，再刷新并使用第二设备打开；验证高度只统一一次，展示选择按本机和页面保留。
- [ ] 连续执行侧栏新增、命名、语言选择、排序和切块，检查当前块身份、正文及当次会话的光标、滚动和撤销记录。
- [ ] 在新单块展示与堆叠展示中分别于折叠 Markdown 标题末尾回车，再切块、切回和撤销；原内容保持折叠，新同级标题的位置、光标和协同正文正确。单文档模式的新回车行为也需回归。
- [ ] 快速输入后立即切块，另一客户端同时继续编辑非当前块；返回或复制导出时，确认没有丢失输入或采用过期正文。
- [ ] 两个客户端分别选择不同块和展示方式，再执行共享排序、命名、语言修改及删除，验证共享内容更新与本机选择隔离同时成立。
- [ ] 删除当前块直至页面为空，关闭重开并从另一设备打开，再新增第一个块；零块状态和后续编辑正常。
- [ ] 在窄屏与触摸场景验证侧栏导航、管理菜单、拖拽及边缘自动滚动；记录使用的真实设备或模拟方式，模拟通过不冒充真实设备通过。
- [ ] 执行项目类型检查、完整测试、构建、变更文件格式检查和差异检查；检查失败时修正并重验，不能仅列出计划命令作为通过证据。
- [ ] 验收报告逐项记录已验证、未验证及失败场景。本票完成后再执行 09 的隔夜折叠诊断；本票通过不表示该问题已定位或修复。
