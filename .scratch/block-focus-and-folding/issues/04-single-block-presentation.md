# 04：默认使用单块展示并保留切块时的编辑状态

**What to build:**
用户进入分块工作区时默认只查看当前块，可以切回堆叠展示；切块和切换展示方式都保持编辑连续性，复制与导出仍读取正确内容。

**Blocked by:** 03：通过侧栏选择和定位当前块。

**Status:** ready-for-agent

- [ ] 提供单块展示和堆叠展示的明确切换入口。展示方式按设备、按页面记住，没有记录时默认单块展示。
- [ ] 单块展示仅显示当前块正文，并占满主编辑区域；正文上方显示当前块名称、语言以及复制和导出入口。
- [ ] 单块展示不受堆叠中的块高度或整块折叠状态影响，块内部折叠继续生效；不能为显示当前块而改写共享的整块折叠状态。
- [ ] 切回堆叠展示时恢复各块已保存的高度与整块折叠状态，并定位到同一当前块；切入单块展示时显示当前块。
- [ ] 本次页面打开期间，切块后返回保留各块的光标、滚动位置和撤销记录；展示切换同样不能丢失这些状态。
- [ ] 快速输入后立即切块或切换展示方式，输入和未完成的协同操作仍正确保留。验证方案包含切换时尚未确认的编辑，不能只测试网络空闲时切换。
- [ ] 关闭重开后恢复展示方式、当前块和已有折叠记忆；不新增跨重开保存光标、滚动或撤销记录的要求。
- [ ] 复制和导出继续覆盖原有范围。远端修改非当前块后，读取结果不得直接采用过期缓存，也不得在读取失败时伪装成成功。
- [ ] 空清单显示无当前块的新增入口，不因单块展示而自动创建块；当前块被远端删除时沿用导航票的选择规则。
- [ ] 两个设备的展示方式和当前块相互独立，块正文及原有共享布局继续同步。单文档模式继续保留，两种模式不搬移正文。
- [ ] 实施前核实编辑器、协同连接和正文缓存的生命周期，再选择满足上述行为的实现方式；不预设销毁编辑器是安全的，也不引入无独立用途的基础设施重构。
- [ ] 完成真实浏览器切换、编辑、撤销、折叠和复制导出验证，并检查实际正文、光标、滚动、撤销结果及另一客户端收到的内容；不以编辑器未报错作为验收证据。
