# 分块工作区单块展示与折叠行为

状态：设计已确认，尚未进入实现。

## 目标与范围

本版包含三项工作：调查单文档模式隔夜重开后折叠丢失的问题，调整 Markdown 折叠标题末尾的回车行为，以及增加默认启用的单块展示和侧栏块管理。

单文档模式继续保留。单块展示是分块工作区内的展示方式，两种模式的正文仍相互独立。本版不增加新的编辑形态，不进行正文迁移，也不取消单文档模式。

术语以 [术语表](../../CONTEXT.md) 为准。

## 折叠记忆问题

用户报告：同一设备在单文档模式中关闭页面，约一晚上后重新打开，原有折叠偶尔全部展开。目前不能稳定复现。

此前的模式切换验证不能证明隔夜关闭重开的恢复可靠。本次根因尚未确认，不能把新的保存守卫或恢复重试直接作为修复方案。

诊断必须区分以下结果：

- 关闭前，浏览器是否读到了正确的折叠记录，写入是否到达服务端。
- 重开时，本地缓存和服务端旁路协同文档分别包含什么记录，客户端最终采用哪份记录。
- 保存记录仍然正确时，正文加载、语言确定和折叠范围计算是否使恢复失败。
- 隔夜期间，实际服务实例是否重启或清理了文档，是否启用了持久化。

记录诊断证据时只采集必要的状态、时序和折叠范围，不采集正文或凭据。用可控的关闭重开、延迟加载和服务重启场景缩小原因；按实际证据选择需要运行的场景，不预先认定它们都是缺陷。

只有找到可验证的因果链后才确定修复位置。自动化验证需证明检查能区分修复前后；隔夜实机效果在用户确认前保持未验证状态。

## Markdown 折叠标题末尾的回车

单文档模式和分块工作区中的 Markdown 采用相同行为。

仅在下列条件全部满足时应用新规则：

- 编辑器只有一个光标，没有选区。
- 光标位于已折叠 Markdown 标题的行末。
- 编辑器没有处于输入法组合期间。

按回车后，在当前折叠区的完整内容之后插入同级 Markdown 标题。原内容继续折叠，新标题可见，光标位于标题标记后的空格之后。标题级别沿用原来的
`#` 数量，不复制标题文字。

例如，以下示例中的 `|` 表示光标，不属于正文。操作前的内容为：

```text
## 1|
111
```

当 `## 1` 已折叠且光标位于标题末尾时，按回车后正文为：

```text
## 1
111
## |
```

`111` 继续隐藏，光标位于新插入的 `## `
之后。折叠区内有子标题时，插入位置仍在整个折叠区之后；后面已有同级或更高级标题时，新标题插在该标题之前。

其他位置、其他语言、多光标、选区和输入法组合期间沿用现有回车行为。插入应作为一次可撤销编辑参与现有正文同步。

## 两种展示方式

分块工作区支持单块展示和堆叠展示，提供明确的切换入口。没有本机历史选择时默认单块展示。

展示方式和当前块由各设备分别记住，不随块清单跨设备同步。一台设备切块或切换展示方式，不使其他设备跳转。

单块展示中，当前块正文占满主编辑区域，不受堆叠展示的块高度和整块折叠开关影响。块内部的标题折叠仍然生效。切回堆叠展示时，恢复堆叠展示的块高度和整块折叠状态。

堆叠展示的块正文高度统一调整为 200 像素，不含块头部。此次调整覆盖已有块已保存的高度，新块也使用该默认值。每个页面只进行一次升级调整；完成后用户仍可拖动改变高度，刷新或切换展示方式不得再次重置高度。

块高度、整块折叠和块内折叠继续遵循原有共享规则。统一高度不清除正文、标题、语言、块顺序或折叠记录。

## 侧栏与块管理

侧栏列出页面全部块，标明当前块，支持选择和跳转。每个块提供命名、语言选择、删除和排序菜单，以及专用拖拽手柄。

块格式沿用现有语言类型，包括 Markdown、JSON、XML 和纯文本等。名称允许重复，块身份不依赖名称或排序位置。

侧栏拖拽支持鼠标和触摸。拖拽接近列表边缘时自动滚动。命名、菜单操作和正文选择不触发排序；拖动期间只预览顺序，松手提交排序。

单块展示的正文上方显示当前块名称、语言和复制、导出入口。堆叠展示保留现有块头部操作。侧栏操作与块头部操作修改同一份块数据。

### 新增块

从侧栏新增时，插在当前块之后，立即选中新块并进入命名，默认语言为纯文本。页面为空时，新建第一个块并采用相同行为。

现有堆叠展示顶部和底部的新增入口继续分别在开头和末尾插入。

### 删除块

删除前显示包含块名的确认提示。删除当前块后优先选择原顺序中的后一个块，没有后一个时选择前一个。删除其他块不改变当前块。

允许删除最后一个块。零块页面显示新增入口，刷新或关闭重开后仍然为空；不能因块清单为空而自动恢复默认块。

删除的范围沿用现有块清单操作。本版不增加服务端孤立正文清理或块回收站。

## 切块与编辑连续性

本次页面打开期间，切换块后再返回，保留该块的光标、滚动位置和撤销记录。切换前输入不能丢失；正在同步的正文操作不能因界面切换而被丢弃。

关闭后重开，恢复当前块、展示方式和已有折叠记忆。不要求恢复各块的光标、滚动位置或撤销记录。

单块展示不能让已有复制和导出功能返回切块前的过期正文。具体编辑器与协同连接生命周期由实现阶段根据这些约束决定，本记录不指定挂载策略。

## 当前块的选择与定位

1. 本机的展示方式和当前块按页面分别记住。没有有效当前块记录时选第一个块；空页面没有当前块。
2. 堆叠展示中，点击侧栏项会选中该块并滚动到它；若整块已折叠，先定位到块头部，由用户决定是否展开。直接编辑另一个块时，该块成为当前块。
3. 从堆叠切到单块展示时显示当前块；切回堆叠时定位到同一块。排序后仍选中同一块，不随数组位置选中其他块。
4. 远端删除当前块时，按本机删除相同的顺序规则选择相邻块；若无法从已有顺序确定相邻块，则选择当前清单中的第一个块。远端排序不使本机跳块。

## 验证计划

先完成功能开发与组合验收，再开始隔夜折叠问题诊断。实现阶段按以下顺序验证；本次讨论尚未执行产品行为验证。

1. 使用项目已有测试入口 `npm test`
   检查新增、排序、删除、空清单重开和高度迁移。高度迁移必须验证首次统一为 200 像素，之后手动改高再重开不会被重置。
2. 用真实编辑器验证 Markdown 回车：覆盖标题级别、子标题、文末、后继标题、无选区和排除条件，并检查正文、隐藏范围、光标、撤销及另一客户端收到的正文。单文档和块编辑器都需执行。
3. 用真实浏览器验证单块与堆叠切换、侧栏管理、鼠标与触摸拖拽、边缘滚动、窄屏可达性及空页面新增。
4. 在两个客户端验证展示选择相互独立、块清单仍共享，以及远端排序或删除时当前块的处理。快速输入后切块，再返回检查内容、光标、滚动和撤销；远端修改非当前块后验证复制与导出不会返回旧缓存。
5. 执行 `npm run check`、`npm test` 和 `npm run build`，对变更文件执行格式检查和
   `git diff --check`。这些检查不能代替浏览器或隔夜实机验证。
6. 建立折叠丢失的失败证据。用真实浏览器记录保存、关闭和重新加载各阶段的折叠状态，对照旁路协同文档；在复现前不宣称已修复。
