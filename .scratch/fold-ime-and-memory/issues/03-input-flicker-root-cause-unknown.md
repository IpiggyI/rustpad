# 03: 输入时正文闪成其他字 — Monaco 输入缓冲区坐标混用

**What to build:**
打字（尤其中文输入法组合）时，已有正文有时会短暂显示成文档里别处的字，空格或回车结束输入后恢复。需要找到真正的因果链并修掉，而不是再加一层与症状相邻的守卫。

**Blocked by:** 无

**Status:** needs-triage

2026-09-11：根因已定位，加载器修复已实施，浏览器复现检查通过；报告人在 Windows 小狼毫原机确认输入闪烁不再出现。完整证据见 [诊断记录](../diagnostics/root-cause.md)。

## 仍成立的症状（报告人，非 100%）

- 输入过程中原有文字一闪，变成其他文字；敲空格或回车结束输入后停止。
- markdown 下把最下方可折标题折叠后更容易出现；闪出的字刚好是折叠后仍可见的那一行。
- 最后一节展开时也可能发生，该规律盖不住全部异常。
- 把闪烁时出现的字在文档里找出来删掉再撤回，下一次会换成别的字。

## 已落地但未消除症状的尝试（不得再当根因）

| 时间 | 做法 | 结果 |
|---|---|---|
| `1e3b4b1` | 标题/名字改 `ImeInput`；组合期间跳过远程光标 `deltaDecorations` | 正文闪烁仍在 |
| 2026-09-11 本目录 01 | 组合整段 no-op `FoldingController.triggerFoldingModelChanged`，结束再 trigger；组合期间不 persist/restore 折叠 | 本地实机闪烁仍在 |

同日实机：折叠记忆（02）反复切模式未再丢。因此本症状不是「切模式把折叠写丢再套回来」。
