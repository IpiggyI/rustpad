# 粘贴图片与图片预览

Status: ready-for-agent

## 问题陈述

用户想在协同文档里放截图和照片，并且能直接看到图片或点开原图。编辑器是纯文本的 Monaco，协同层对纯文本做字符级 OT，所以图片本身不能进正文，正文里只能放图片引用。图片存在服务端磁盘目录里，正文用相对地址引用它，决策见
[ADR 0007](../../docs/adr/0007-images-on-server-disk-referenced-by-relative-path.md)。术语（图片、图片引用、图片预览）见根目录
`CONTEXT.md`。

分两期交付：第一期能添加图片并按住 Ctrl 点开；第二期在图片引用下方显示图片预览。

## 用户故事

1. 作为电脑端用户，我截图后在任意块或单文档里按 Ctrl+V，正文出现一段图片引用，其他人同步看到这段文本。
2. 作为手机用户，我点"上传图片"按钮，从相册选一张照片，正文出现一段图片引用。
3. 作为读者，我按住 Ctrl（macOS 上是 Cmd）点击图片引用，在新标签页里看到原图。
4. 作为从 Excel 或 Word 复制内容的用户，我粘贴后得到的仍是文字，不会多出一张截图。
5. 作为服务端管理者，我设置 `IMAGE_DIR` 才开启上传；没设置时，用户添加图片会看到明确的提示。
6. 作为读者，我在图片引用下方直接看到图片预览；在手机上点预览就能打开原图。（第二期）

## 实现决策

### 服务端

- 新环境变量 `IMAGE_DIR` 指定图片目录，`ServerConfig` 增加对应字段。不设置时不接受上传，与 `SQLITE_URI`
  不设置就不持久化的做法一致。目录不存在时，第一次上传自动创建。
- `POST /api/images`：请求体是图片的原始字节，上限 10 MiB（10 × 1024 × 1024 字节）。服务端按文件头判断格式，只接受
  png、jpeg、gif、webp，不信任请求声明的类型。成功时返回 JSON `{"path":"api/images/<图片id>.<扩展名>"}`，扩展名为
  `png`、`jpg`、`gif`、`webp` 之一。
- 失败状态码：未开启上传返回 503；格式不支持返回 415；超过上限返回 413；写盘失败返回 500，并记录带原因的错误日志。响应体是一句英文说明，前端直接展示。
- 图片 id 由服务端随机生成，只含小写字母和数字，长度足以忽略碰撞。写文件不得覆盖已有文件；没写完的文件不得以最终文件名出现在目录里。
- `GET /api/images/<图片id>.<扩展名>`：只接受这一种文件名格式，其他名字一律 404。`Content-Type`
  按扩展名设置，带 `X-Content-Type-Options: nosniff`。图片写入后永不改写，所以响应可以长期缓存。未开启上传时返回 404。
- 服务端从不删除图片，这是有上限的简化，代码里要带 `shortcut:` 标记。
- `README.md` 的 Configuration 一节写明 `IMAGE_DIR`。开发用的 `.env` 开启它，开发时生成的图片目录加入
  `.gitignore`。

### 前端（第一期）

- **粘贴规则**：剪贴板里的 `text/plain` 非空时，照原样粘贴文字，不上传任何东西；`text/plain`
  为空且有图片文件时，拦截这次粘贴并上传图片。编辑器只读时不拦截。
- **插入内容**：每张图片插入一段 `![image](api/images/<图片id>.<扩展名>)`。一次添加多张时按剪贴板或选择顺序插入，用换行分隔。有选区时替换选区。
- **上传期间**：只在本机显示"上传中"标记，正文不变，其他人看不到任何东西。插入位置用随编辑移动的标记跟踪，因为上传期间远端编辑会移动位置，不能保存一个固定的字符偏移量。上传完成后作为本地编辑插入，经现有
  OT 客户端同步。
- **失败**：移除"上传中"标记，用 toast 提示原因：服务端未开启上传、格式不支持、超过 10 MB、网络错误。上传前先在客户端检查格式和大小，超限时不发请求。
- **上传按钮**：每个块的头部和单文档头部各放一个"上传图片"按钮，打开文件选择（可多选，只接受四种格式），图片引用插入到对应编辑器的当前选区。
- **打开原图**：对所有语言注册链接识别，把图片引用里的相对地址按当前页面地址解析成完整地址，Ctrl 或 Cmd 加点击在新标签页打开。
- **接入点**：块编辑器（`src/BlockEditor.tsx` 的 `onMount`）和单文档模式（`src/SingleDocView.tsx` 的 `onMount`）都要接入。
- 所有块都能添加图片，不区分块的语言。界面文字用英文，与现有界面一致。

### 前端（第二期：图片预览）

- 地址是 `api/images/<图片id>.<扩展名>` 的图片引用，在它所在行的下方显示图片预览。所有语言、两种编辑器都显示。其他地址（外链图片）不预览。
- 预览宽度不超过编辑区，高度不超过 320 像素，保持原图比例。点击预览在新标签页打开原图，这是手机上打开原图的方式。
- 图片加载失败时，在预览位置显示一行简短的英文错误说明。
- 图片引用所在行被折叠时，预览随之隐藏。
- 预览不改正文，不写布局状态，不改变块高度。块高度是固定值，内容超出时在编辑器内部滚动。
- 正文变化后（本地或远端），预览跟着更新。已经加载过的图片不应让编辑器内容上下跳动。

## 非目标

- 富文本或所见即所得编辑；把粘贴的 HTML 转成 markdown。
- 通用附件（PDF、压缩包等）。
- 图片回收、删除接口、按页面控制访问。
- 拖放上传。
- 外链图片的预览。
- `intranet` 分支的合并，以及内网版 `.env`、《使用说明》的更新。这些另行处理。

## 待人工验证

- 手机浏览器的粘贴事件能否带出图片文件；iOS 选择照片时是否转成 JPEG。
- 通过局域网 IP 的纯 HTTP 页面粘贴图片。
- Firefox 的"复制图片"是否同时在剪贴板里放入 `text/plain`；若放入，按粘贴规则会粘贴文字。
