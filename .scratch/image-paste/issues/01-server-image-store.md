# 01：服务端保存和提供图片

**What to build:**
服务端增加图片上传和读取两个接口，图片保存在 `IMAGE_DIR` 指定的目录里。接口形状、状态码、文件名格式和响应头见同目录
`spec.md` 的"服务端"一节，那一节是本票的约束。

**Blocked by:** 无

**Status:** ready-for-agent

- [ ] `IMAGE_DIR` 未设置时，上传返回 503，读取返回 404
- [ ] 上传 png、jpeg、gif、webp 成功，返回 `{"path":"api/images/<图片id>.<扩展名>"}`；之后用该地址读取，得到相同字节和正确的 `Content-Type`
- [ ] 读取响应带 `X-Content-Type-Options: nosniff`
- [ ] 格式按文件头判断：SVG、纯文本、伪装成 png 的其他内容返回 415
- [ ] 超过 10 MiB 返回 413，目录里不留下文件
- [ ] 不符合 `<图片id>.<扩展名>` 格式的文件名（含路径穿越）返回 404
- [ ] 目录不存在时，第一次上传自动创建
- [ ] 写文件不覆盖已有文件；没写完的文件不以最终文件名出现
- [ ] 不删除图片这一简化带 `shortcut:` 标记
- [ ] `README.md` 写明 `IMAGE_DIR`；开发用 `.env` 开启上传，开发时生成的图片目录加入 `.gitignore`
- [ ] 服务端测试覆盖以上行为，至少一条在格式判断缺失时会失败
