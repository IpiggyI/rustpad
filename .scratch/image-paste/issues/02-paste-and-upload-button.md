# 02：粘贴图片、上传按钮和打开原图

**What to build:**
在块编辑器和单文档编辑器里，粘贴图片或用"上传图片"按钮选图，都会上传图片并在正文插入图片引用；按住 Ctrl 或 Cmd 点击图片引用，在新标签页打开原图。规则见同目录
`spec.md` 的"前端（第一期）"一节，那一节是本票的约束。服务端接口由 01 提供。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 剪贴板 `text/plain` 非空时照原样粘贴文字，不上传
- [ ] 剪贴板只有图片时上传，并插入 `![image](api/images/<图片id>.<扩展名>)`；多张按顺序用换行分隔；有选区时替换选区
- [ ] 编辑器只读时不拦截粘贴
- [ ] 上传期间只在本机显示"上传中"标记；插入位置跟随编辑移动，上传期间远端插入文字后，图片引用仍落在原来的逻辑位置
- [ ] 插入作为本地编辑经 OT 同步，另一个客户端看到同样的文本
- [ ] 失败时移除标记，toast 说明原因（未开启、格式不支持、超过 10 MB、网络错误）；超限或格式不对时不发请求
- [ ] 每个块头部和单文档头部各有一个"上传图片"按钮，可多选，只接受四种格式
- [ ] 所有语言都能 Ctrl 或 Cmd 点击图片引用，在新标签页打开按当前页面地址解析出的完整地址
- [ ] 类型检查通过
- [ ] 前端测试覆盖粘贴规则和链接识别，至少一条在规则写反时会失败
- [ ] 浏览器测试：在真实页面里粘贴一张 png，正文出现图片引用，该地址能读回 `image/png`
- [ ] 实机验证：手机上用"上传图片"按钮从相册选图
- [ ] 实机验证：通过局域网 IP 的纯 HTTP 页面粘贴截图
