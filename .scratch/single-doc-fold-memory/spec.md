# 普通模式：折叠记忆（任意语言、跨设备）

Status: ready-for-agent

## 问题陈述

折叠记忆必须是通用的：任意 Monaco 能折的语言，切模式、刷新、换设备后都还折着。只记本机、或只记 markdown，都不算修好。

块模式已经把折叠写进块清单，A 设备折了 B 设备能看到。普通模式目前只写 `localStorage`，换设备会丢。

普通模式与块模式仍是两份独立工作区，切换不搬正文或折叠。本票只让普通模式的折叠记录也走协同存储。

## 用户故事

1. 作为多设备用户，我想在 A 设备普通模式里折上的 markdown / JSON / XML 区域，用 B 设备打开同一文档时仍然折着。
2. 作为普通模式用户，我想切到块模式再回来、以及本机刷新，折叠仍在。
3. 作为普通模式用户，我想同一文档不同语言的折叠互不覆盖，跨设备也是按语言分的。
4. 作为普通模式用户，我想折叠后立刻切换模式，当前语言的折叠仍然保住。
5. 作为块模式用户，我已经有的折叠记忆保持不变。

## 实现决策

- 数据源：旁路协同文档，id 为 `folds:${文档id}`，一份 JSON 对象，键是语言，值是该语言的 Monaco 折叠 memento。键排序后序列化，便于最小差异 OT。决策写入 `docs/adr/0003-single-doc-folds-in-sidecar-collab-doc.md`。
- 客户端用现有 `RustpadHeadless` 读写这份文档，不改 rustpad-server 协议或数据库。
- 本地 `single-doc:folds:${id}:${language}`（及 markdown 遗留键）只是缓存：连上旁路文档之前用来恢复；卸载时同步写出。
- 初始化对齐 `useManifest`：旁路文档尚无可用 JSON 时，把该文档 id 下**所有语言**的本地缓存播种进去，只播种一次。History 到达后服务端为准；解析失败则恢复第一个 JSON / 最近有效值并规范化写回。初始化之后不得再用本地缓存覆盖服务端。
- 写入当前语言时合并进整份语言映射再 `replaceContent`，不得把其它语言的键丢掉。
- 卸载：先同步写本地缓存，再对仍打开的 socket `replaceContent`，然后 `dispose`。
- `#folds:…` 在 `parseHash` 里视为保留前缀，不得当作普通模式文档打开。
- 块模式继续写块清单。两种模式不互拷折叠。

## 非目标

- 普通模式与块模式之间传递折叠或正文。
- 个人视图隔离（无账号；共享即同步）。
- 给没有 Monaco 折叠范围的语言发明折叠规则。
- 重建结构感知同步层（天花板见 ADR 0002）。
